# Restroworks CMS (Payload + Next.js)

CMS app built with **Payload CMS v3.52.0**, **Next.js 15.5.0**, and **React 19.1.0**.

## 🚀 Setup

```bash
npm install
npm run dev:cms
```

CMS runs at:

- Admin: http://localhost:3000/admin
- API: http://localhost:3000/api

## 📂 Highlights

- payload.config.ts → collections & blocks
- collections/ → Users, Pages, Media, Features etc.
- blocks/ → Hero, Content, Testimonial

## 🏗 Modeling

- Pages collection with modular blocks
- Media collection for assets
- SEO fields for optimization

## ✍️ Editing

1. Login `/admin`
2. Manage Pages
3. Add blocks and save
